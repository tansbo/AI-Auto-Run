# AI自动跑局 / AI Auto-Run

面向《杀戮尖塔 2》的 **AI 全自动跑局** Mod：不止帮你算一场战斗，而是从开局一路帮你打到通关/失败——选路、事件、药水、金币、篝火、遗物、抓牌都由 AI 自动决策并执行；战斗内部沿用异步求解引擎算出最优打法。

## AI Auto-Run 能做什么

### 🗺️ 跑局自动游玩（从 Neow 到 Boss）
- **自动开局**：Neow 先古遗物按净价值三选一（诅咒/代价类遗物不再一刀切拒绝，按"效果 − 代价"评估）；
- **自动地图选路**：每次选路对"当前节点到幕末 Boss 的整张地图"做危险度感知的全路线评估（记忆化回溯）——血量越低越避精英、药水当保险、战士战后回血让战斗风险下降，低血时篝火/宝箱/商店相对变值；
- **自动事件处理**：58 个事件全部反编译建目录，选项做**收益 − 代价综合估值**——可 SL（能看清具体奖励）用实际卡/遗物价值，不可 SL（点击才随机）用按池加权的期望；桥事件会"好卡掉血换重抽、垃圾卡直接移除"，迷失鬼火没能力牌就不拿遗物；
- **自动奖励/商店/篝火/宝箱/Boss**：选牌与遗物评分、购买/移除决策、篝火"升级 or 回血"按路线与血量风险决策、宝箱/假商人等特殊房间全部自动通过；
- **药水与金币经济**：战斗外只喝果汁/鲜血药水腾栏位（其余只能丢弃）；保留成本随前方路线危险度浮动；幕末按 A2+「Boss 后只回 80% 缺失生命」规则省药、低血出 Boss；金币价值随本幕商店可达性与事件金币门槛（实测 ≥100/120/125/149）浮动——没商店时金币不值钱，能安全快速到商店时才值钱。

### 🧠 数据驱动的评分与持续校准
- **卡牌评分**接入社区真实对局统计（Spire Codex A10：winRate/pickRate，483 张 × 数百万次抓牌），评分带真实胜率差加成；
- **先古遗物池**（Neow/Orobas/Darv/Tezcatara/Vakuu/Nonupeipe/Pael/Tanx 等 9 个先古、70+ 遗物）按反编译效果逐件建表，含随卡组协同（如能力牌遗物按能力牌数估值）与路线/金币上下文；
- **匿名遥测（opt-in）**：可把每局对局统计（种子/角色/难度/层数/抓牌/遗物/胜负）自动上传收集，用于持续改进 AI（接收端示例见 `tools/telemetry_receiver.py`）。

### ⚙️ 使用与集成
- 设置页（主菜单可访问）：总开关 + 快速模式/失败停止/调试日志/种子重放（A/B 训练）/遥测开关与上传端点；
- 战斗内沿用 Combat Solver 引擎：可只看推荐路线、执行本回合，或由 AI 自动接管整场战斗（跨回合搜索、路线复用、三态药水策略等，见下节"局内引擎"）；
- 单人模式下全自动；搜索与跑局决策均不修改游戏 RNG。

## 局内引擎（继承自上游 Combat Solver）

战斗内部沿用 Combat Solver 的异步求解引擎：进入战斗后在主线程捕获稳定根，后台对根派生的影子状态做跨回合搜索（手牌、牌堆、敌人行动、药水、遗物、选牌与持续效果），给出推荐路线、预计战损与关键行动；支持仅查看 / 执行本回合 / 连续全自动、原生选牌流程、跨回合路线复用、可调搜索预算（低/中/高/极高，2-8 路并行）与界面通知。详细引擎文档见上游 [Combat Solver](https://github.com/Torch1230/CombatSolver)；本项目文档见 `docs/`（ARCHITECTURE / DEVELOPMENT_NOTES / TEST_MATRIX）。
